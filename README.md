# Excel Data Analysis Assignment

Basic data exploration using Microsoft Excel on a product dataset.

## Functions Used

**1. Basic Statistical Functions**
- `=SUM(D2:D33)` – Calculate total price
- `=COUNT(D2:D33)` – Count products
- `=AVERAGE(D2:D33)` – Calculate average price
- `=MIN(D2:D33)` – Find minimum price
- `=MAX(D2:D33)` – Find maximum price

**2. Logical Function**
- `=IF(D2>=500,"High Price","Standard Price")` – Categorize products based on price.

**3. Conditional Functions**
- `=SUMIF(F2:F33,"Electronics",D2:D33)` – Calculate total price of Electronics products.
- `=COUNTIF(D2:D33,"<100")` – Count products priced below $100.

**4. Text Functions**
- `=LEFT(A2,2)` – Extract Day.
- `=RIGHT(A2,2)` – Extract Country Code.
- `=MID(A2,4,3)` – Extract Month.

## Results

- Total Products: 32
- Total Price: $9,100
- Average Price: $284.375
- Minimum Price: $30
- Maximum Price: $1,000
- Electronics Total: $7,100
- Products Below $100: 10
